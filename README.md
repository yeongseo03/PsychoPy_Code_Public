# 물류 코드 검수 실험 실행 안내

## 실행 환경

이 실험은 실험 폴더 안의 `.venv` 가상환경에서 PsychoPy 라이브러리만 사용합니다. Builder 데스크톱 앱은 설치하지 않으므로 다운로드와 설치 부담을 줄였습니다. 기본 Python/Anaconda 환경은 변경하지 않습니다.

## 사전 점검

1. 모니터를 60Hz 이상으로 설정하고, 키보드에서 F와 J가 정상 입력되는지 확인합니다.
2. 같은 공용 컴퓨터와 같은 이어폰을 모든 참가자에게 사용하고, 참가자 위치를 화면에서 약 50cm로 표시합니다.
3. 시스템 출력 음량을 30%로 설정한 뒤 아래 사전 점검 명령을 실행합니다.

   ```powershell
   .\run.ps1 --sound-check
   ```

4. 안내 화면에서 스페이스를 눌러 경고음을 확인합니다. 연구팀이 먼저 리허설해 잘 들리고 불편하지 않은지 확인하고, 필요하면 본 실험 전에 공통 시스템 음량을 한 번 조정한 뒤 전 참가자에게 동일하게 유지합니다. PsychoPy의 디지털 신호 크기는 코드에서 고정되어 있습니다.

## 실험 실행

Windows에서는 먼저 PowerShell에서 이 폴더로 이동해 환경을 한 번 설치합니다.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup.ps1
```

설치가 끝나면 다음처럼 소리 확인 후 실험을 실행합니다.

```powershell
.\run.ps1 --sound-check
.\run.ps1
```

기존 CSV가 있고 일부 **완료된 블록**만 들어 있다면, 참가자 번호를 동일하게 입력한 뒤 다음 명령으로 빠진 블록부터 이어갈 수 있습니다. 이미 기록된 행은 추가하거나 덮어쓰지 않습니다.

```powershell
.\run.ps1 --resume
```

블록 도중에 중단되어 해당 블록이 40회 미만이면 자동 이어 실행을 막고 기존 CSV를 보존합니다.

### macOS

맥에서는 Windows용 `.ps1` 파일을 사용하지 않고 터미널에서 실행합니다. Python 3.11이 없다면 [Python macOS 다운로드 페이지](https://www.python.org/downloads/macos/)에서 먼저 설치합니다. [PsychoPy 공식 설치 안내](https://psychopy.org/download.html)에 따르면 PsychoPy 2026.2 계열은 Python 3.11을 지원하며, 이 실험의 `.py` 파일을 실행하기 위해서는 PsychoPy 라이브러리만 설치하면 됩니다.

```bash
cd "/압축을_푼_실험_폴더_경로/PsychoPy_물류코드실험"
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install psychopy
python experiment.py --sound-check
python experiment.py
```

`cd` 명령의 경로는 실제 폴더 위치로 바꿉니다. 예를 들어 바탕 화면에 압축을 풀었다면 `cd "$HOME/Desktop/PsychoPy_물류코드실험"`을 사용할 수 있습니다. `python3.11` 명령을 찾을 수 없으면 Python 3.11 설치를 먼저 확인합니다. 설치가 끝난 뒤 터미널을 새로 열어 실행할 때는 실험 폴더로 이동한 다음 `source .venv/bin/activate`를 실행하고 `python experiment.py`를 실행합니다.

참가자가 사용하는 소리 환경을 맞추기 위해 실제 자료 수집은 안내된 공용 PC와 같은 이어폰에서 진행합니다. 맥에서 설치 확인을 할 때는 `--sound-check`만 실행하고, 실제 참가자 자료는 만들지 않도록 합니다.

참가자 번호 1–12를 입력하면 블록 순서와 F/J 키 배정이 자동 배정됩니다. 키 역할은 참가자 사이에 균형을 맞춰 바뀌므로, 참가자에게 화면 안내를 따르도록 설명한 뒤 연습부터 진행합니다. 블록 사이에는 화면 안내에 따라 1분 휴식합니다. ESC를 누르면 중단할 수 있으며, 완료된 본 시행은 CSV에 남습니다.

키 입력은 PsychoPy의 직접 이벤트 큐에서 읽으므로 PsychHID 초기화를 거치지 않습니다. 반응시간은 키 이벤트 타임스탬프를 기준으로 기록하며, 화면 갱신과 입력 처리에서 화면 한 프레임 정도의 오차가 생길 수 있습니다.

## 자료 저장과 주의사항

- 실제 참가자의 본 시행만 `data/P01_trials.csv`와 같은 이름으로 저장합니다. 예시 결과나 모의 측정값은 만들지 않습니다.
- 같은 참가자 번호의 CSV가 이미 있으면 덮어쓰지 않도록 실행을 멈춥니다. 재실행 전에 기존 파일을 안전한 별도 위치에 보관하고, 재실험 이유를 기록하세요.
- 오류가 발생하면 완료된 시행은 CSV에 남고, 오류 내용은 `data/P01_error.txt`와 같은 파일에 저장됩니다. 화면 안내에서 스페이스를 누르면 종료합니다.
- `Defect`와 `Alarm`은 독립 변수로 기록됩니다. 둘을 하나의 상태 코드로 합치지 마세요.
- 첫 전체 실행은 참가자가 아닌 연구팀이 절차를 리허설하는 데 사용하고, 그 자료는 본 분석에 포함하지 마세요.
- 실제 참가자 자료를 수집하기 전, 담당 조교와 동의 안내, 연습 미달 처리, 경고음 수준, 피드백 방식을 확인하세요.

## 기록 변수

CSV에는 참가자 ID, 블록/시행 번호, 블록 순서와 키 배정, 조건, 오경보율, 제한 시간, 두 코드, 실제 결함 여부, 경고 여부, 판단 응답과 실제 키, HIT/MISS/FA/CR 분류, 반응시간, 정확도, 제한시간 초과 여부가 기록됩니다. `Response`는 키 문자가 아니라 정상=0/결함=1로 기록됩니다. 무응답은 반응시간과 정확도를 빈칸으로, `Type=NR`, `Timeout=1`로 저장합니다.
